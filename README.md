# ThinkPulse – Webcam Posture Tracker

ThinkPulse is a browser-based webcam posture tracker that analyzes posture using your device camera.

## Features

- Webcam posture detection
- Neck angle analysis
- Shoulder angle analysis
- Real-time posture feedback
- Runs directly in the browser
- Camera data stays on the device
- Phone alarm/notification for poor posture
## Live Demo

Try ThinkPulse directly in your browser.

The project uses a QR code to connect the user's phone/device to the live posture-tracking experience.

## How It Works

1. Open the ThinkPulse live demo.
2. Scan the QR code using your phone.
3. Connect your device.
4. Allow camera access.
5. ThinkPulse analyzes neck and shoulder angles.
6. The system provides posture feedback and alerts.
